# 赤石 Akaishi

> 以「赤石」为核心驱动的科技与生物改造模组 — Minecraft 1.20.1 · Forge

**采集赤石矿脉，构筑能量网络；移植生物器官，改写自身血脉。**

《赤石 Akaishi》是一款以「赤石」为能源基石的科技与生物改造模组。从赤石矿脉与赤水晶起步，搭建赤能源网络与矩阵反应堆，将矿石化作电力与燃料；再深入生命科技——采集生物样本、解构基因、培育器官、移植入体，以排异为代价换取超越凡躯的力量，最终建立全自动的生产线与属于自己的进化之路。

---

## 玩法主线

一条自给自足的科技树，从矿镐到超自然：

```
采集赤石 → 打粉 / 变化 / 压缩 → 赤能源网络 → 矩阵反应堆发电
                                        ↓
             生命能量 → 样本采集 → 基因分析 → 器官培育 → 手术移植
                                        ↓
                        药剂 / 词条 / 排异平衡 → 超越凡躯
```

## 核心系统

### 资源与材料加工

- **赤石矿脉**：主世界 / 深板岩 / 下界 / 末地四种环境 × 低/中/完美/无瑕四档浓度，共 16 种矿石
- **三级加工链**：打粉机磨制粉末 → 变化器转化为矿物基底 → 压缩机压制粉末成块；粉末与基底深度参与各级机器、管道与饰品配方
- **赤水晶**：晶洞生成，瑕疵 → 普通 → 完好 → 完美四级母岩，催化器逐级升阶，自动收集器代工采集

### 能量体系

| 层级 | 载体 | 来源 |
|------|------|------|
| 赤能源 | 能量细胞 / 管道 | 燃烧赤石晶、精华块；能量发生机、发生器矩阵 |
| 生命能量 | 生命管道 / 储存器 | 聚合转换架构消耗赤能源聚合，更高级的能量形态 |
| 燃料 / 等离子体 | 7 种反应堆燃料 → 3 种等离子体 | 液化装置、燃料混合器、能量加工器、聚变聚合器 |

能量逐级跃迁：赤能源 → 下界至纯 / 复合能量 → 七种反应堆燃料 → 衰竭燃料 → 活化液体 → 等离子体，每条链都有专属机器与闭环回收。

### 多方块结构

| 结构 | 尺寸 | 亮点 |
|------|------|------|
| 反应堆 | 5×5×5 ~ 7×7×7 | 燃料棒 × 散热片；400~700℃ 最优产率，超温减产不停机，1000℃ 触发 10 秒爆炸倒计时并留下「衰竭区域」 |
| 聚变堆 | 7×7×7 | 温度以百万计（50M 起步），效率框架 × 散热框架 × 燃料框架三向博弈 |
| 矿机 | 9×9×5 镂空塔 | 钻头打出信标光束，速度 / 时运 / 储能升级模块按等级解锁 |
| 无线终端 | 5×5×5 | 跨维度传输、区块弱加载、损耗抑制组件 |
| 矩阵 | 3×3×3 / 5×5×5 | 发生器矩阵 45 倍 → 高级 200 倍、提纯矩阵、生命转换矩阵、超级发生器核心 |

### 衰竭区域

反应堆失控的代价：污染等级按 3 的次方区块梯度扩散（泄漏 3 区块 → 爆炸 81 区块），持续 30 小时。区域内禁生生物、暗紫雾笼罩，草皮枯死、山石腐化，亡灵生灵化为凋零骷髅系——直到衰变净化塔以 10 倍速将其驱散。

### 器官移植与基因

```
样本采集 → 生命分析台解构 → 生命结构台构造 → 培养舱提纯 / 品质升级
         → 培育器施加突变词条 → 手术仓移植 / 摘除
```

- **9 个器官位**：眼、心、肺、脏器、肾、双臂、双腿，各绑定生物来源与品质档位（I~IV）
- **排异机制**：排斥值上限 100，负面阈值、躯体超载、天敌反噬、日光自燃负面——移植并非没有代价
- **突变词条**：三档稀有度，良性 vs 畸变双刃剑，词条重铸仪可原位重铸
- **基因强化**：永久药剂吸收基因型，同源器官互为增幅；排异中和剂清洗减轻负担

### 药剂系统

- **永久药剂**：吸收基因型，永久强化同源器官适配
- **突破药剂**：三向临时爆发（均衡 / 狂涌 / 深沉），药剂台调配、药剂库存储

### 无线网络

身份卡即钥匙的赤能源无线终端——输入 / 输出口、跨维度传输、区块弱加载、损耗抑制组件，参考 MEK 量子传输，远程供能不再受距离束缚。

### 物流管道

物品（4 级，1~64 个/tick）/ 液体 / 废料 / 等离子体 / 赤能源（4 级）/ 生命能量管道全家族覆盖；废料与等离子家族按族隔离，普通罐体对第三方物流（漏斗、MEK、AE2）全面开放。

### 装备与升级

- **赤石装备**：基础属性为下界合金 ×1.25，装备打造器 4 点基础升级 + 升级台高级能力（吸血、击退、移速、防火、防爆、区域破坏、掉落精华等）
- **机器升级**：速度 / 能量升级组件，矿机专用升级模块
- **Curio 饰品**：7 件（饱食、狩猎、采集、防火、防爆、净化、凋零防护）

### 附加内容

- **转基因工厂**：凋零骷髅基因序列 + 缠怨藤 + 凋零玫瑰 → 凋零藤作物体系
- **母神祭坛**：5×5 底座 + 四角柱，NBT 献祭识别与悬浮供奉
- **游戏内手册**：《赤石研究日记》（科技主线）、《生命的奥秘》（器官与药剂）、《基因详解》（全数值查表）三本帕秋莉手册
- **JEI 集成**：12 个配方类别全覆盖
- **配置系统**：`config/akaishi-common.toml` 全量数值可调，游戏内 Cloth Config 界面热重载即时生效

## 构建与开发

```bash
./gradlew build
```

产物位于 `forge/build/libs/`。开发环境调试可用：

```bash
./gradlew :forge:runClient -Dakaishi.gametest=1
```

（GameTest 自动核验器官注册无孤儿 / 死链，见 `AkaishiOrganRegistryChecker`）
