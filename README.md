# 赤石 Akaishi

一个以「赤石」为核心的 Minecraft 1.20.1 科技模组，基于 Architectury 框架开发（当前面向 Forge 平台）。

采集赤石矿脉与赤水晶，构筑赤能源网络，搭建矩阵反应堆发电；移植生物器官强化自身，调配药剂，建立属于自己的自动化生产线。

## 玩法总览

- **资源采集**：赤石矿、赤水晶、晶簇与晶洞，多环境多阶矿石
- **赤能源**：能量细胞、能量生成器、能量液化/串联/聚合，构建跨区块能量网络
- **矩阵反应堆**：燃料棒与散热片组成 5×5/7×7 多方块结构，400-700℃ 最优产率；超温减产不停机，满热量 10 秒倒计时爆炸并留下半径 5 区块的「衰竭区域」
- **衰竭区域**：持续 30 小时的衰变减益与魔法伤害，草皮退化为砂土、生灵化为僵尸，区域可被反应堆事故与衰竭桶泄漏触发
- **无线网络**：身份卡即钥匙的赤能源无线终端——输入/输出口、跨维度传输、区块弱加载、损耗抑制组件，参考 MEK 量子传输
- **生命能量**：生命矩阵、聚合转换架构、生命能量细胞与管道，赤能源之上的更高形态
- **衰竭燃料闭环**：反应堆废料 → 生命活化器无害化 → 离心机分离为活化结晶/衰竭结晶 → 物品重构仪 12 配方嬗变 + 身份卡升级
- **器官移植**：样本采集 → 基因分析 → 培养舱培育 → 手术移植，含排异机制、品质与来源基因、躯体检查仪监控
- **药剂系统**：样本提纯、永久/突破药剂与药剂柜存储
- **生命存储**：器官储藏库、药剂柜、样本保险库
- **物流**：物品/流体/能量管道、自动收集器、燃料投放口与废品输出口
- **装备**：赤石工具与护甲，Curio 饰品（解毒、防火、抗爆、猎杀、寻宝等）

## 环境要求

- Minecraft **1.20.1**，Forge **47.3.0**（Java 17）
- 依赖（同为 Forge 1.20.1 版本）：Cloth Config、Curios、Patchouli（内置手册《赤红手记》《生命秘闻》）、JEI、KubeJS

## 构建

```bash
./gradlew build
```

产物位于 `forge/build/libs/`。
